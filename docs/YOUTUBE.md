## Title

Golden Set: see which support answers break when you edit a help article (Codegeist 2026)

## Description

Golden Set is a Forge app for Jira Service Management, Confluence and Rovo.

It builds a set of verified question and answer pairs from your resolved service requests and ties each one to the Confluence article it relies on. When someone edits that article, Golden Set shows which answers are now likely wrong, suggests corrected answers, and gives you a CSV to re-test your agent in Rovo Agent Evaluations.
